# gym-app
Android App to track gym progress and create customized plans

## Features

* **Categorized Exercise Catalog:** Browse workouts plans and exercises  by name.
* **Animated Visual Guides:** Native rendering of exercise animations (`.gif` / high-resolution images).
* **Workout Routine Logging:** Build, customize, and log training sessions, sets, and rep counts directly from your mobile device.
* **Offline-Ready:** Using SQLite it saves app data locally on the device.
* **Simple Mobile UI:**  Design components tailored for quick single-hand navigation in the gym.

## Device Installation 

### Prerequisites

* [Android Studio](https://developer.android.com/studio) installed.
* **Android SDK:** API Level 24+ (Android 7.0 Nougat minimum recommended).
* **JDK:** Version 17 or higher.
* An Android device with USB Debugging enabled or an active Android Virtual Device (AVD) emulator.

### Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/RS181/gym-app.git](https://github.com/RS181/gym-app.git)
   ```

2. **Open in Android Studio:**
   * Select File > Open... and choose the cloned gym-app root directory.

3. **Sync Gradle:**
    * Allow Android Studio to download dependencies and sync Gradle files automatically (or click File > Sync Project with Gradle Files).

4. **Run the App:**
    * Select your target physical device or emulator from the device dropdown.
    * Click Run (Shift + F10) or press the green Play button in the top toolbar
